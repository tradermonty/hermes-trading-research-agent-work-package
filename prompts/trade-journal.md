Convert the user's trade note into a structured journal entry.

Required fields:
- Date/time.
- Ticker.
- Direction.
- Entry / stop / target if available.
- Position size / risk amount if available.
- Setup type.
- Skill/source that contributed to the idea.
- Thesis.
- Invalidation condition.
- Market regime.
- Emotional/process notes.
- Review date and postmortem trigger.

If essential fields are missing, ask for the smallest set of missing fields. Do not judge the trade outcome prematurely.
