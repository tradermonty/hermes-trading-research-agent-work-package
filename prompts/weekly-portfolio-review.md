Run the weekly core portfolio review.

Focus on long-term holdings, ETFs, dividend holdings, concentration, allocation drift, and forced-review triggers.

Required output:
1. Portfolio state and data freshness.
2. Allocation/concentration risks.
3. Dividend review queue.
4. Holdings requiring manual review.
5. Candidate additions/removals for watchlist only.
6. Tax/account-location notes if relevant.
7. Human next actions.

Frame allocation changes as candidate review items for the human reviewer; this routine does not place orders.
